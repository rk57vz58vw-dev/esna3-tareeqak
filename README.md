# اصنع طريقك — منصة تعليمية

واجهة ويب عربية RTL متجاوبة لجميع المراحل التعليمية، مبنية باستخدام HTML وCSS وJavaScript دون الحاجة إلى تثبيت مكتبات.

## التشغيل
1. فك ضغط الملف.
2. افتح `index.html` في متصفح حديث مثل Chrome أو Edge.
3. يمكنك أيضاً فتح المجلد في VS Code واستخدام إضافة Live Server.

## المميزات الحالية
- لوحة رئيسية ومراحل تعليمية متعددة.
- عرض كورسات تجريبية والبحث والتصفية حسب المرحلة.
- تسجيل كورس وحفظ البيانات محلياً في المتصفح.
- اختبار تجريبي من 5 أسئلة مع تصحيح فوري.
- صفحة تقدم دراسي وحساب طالب.
- وضع ليلي وتصميم متجاوب مع الهاتف.

## ملاحظات مهمة قبل النشر
هذه نسخة أولية Front-end قابلة للتشغيل محلياً. حفظ البيانات يتم على نفس المتصفح باستخدام `localStorage`، ولا يوجد حالياً تسجيل دخول آمن أو قاعدة بيانات أو رفع فيديوهات أو دفع إلكتروني أو لوحة إدارة حقيقية. لا تستخدمها لجمع كلمات مرور أو بيانات طلاب حقيقية.

لتحويلها إلى منصة إنتاجية متعددة المستخدمين، يلزم بناء Backend وقاعدة بيانات ونظام مصادقة وصلاحيات (طالب/مدرس/مدير)، ثم ربط تخزين الفيديو والملفات وخدمات الدفع وفق المتطلبات القانونية والأمنية. يجب أيضاً استبدال المحتوى التجريبي بمحتوى تملك حق استخدامه.
